# 010. Справочник комиссий Wildberries по категориям

## Цель

Страницы под запросы «комиссия wildberries <категория>», «комиссия вб на <предмет>». Данные уже есть: `src/calculator/data/commissionTariffs.json`, 96 категорий и 7 314 предметов с FBO- и FBS-ставками. Нужен хаб и отдельная страница на каждую категорию.

## Что сделать

1. Поставщик `src/app/content/wb-commissions/pages.ts` генерирует из JSON:
   - хаб `/reference/wb-commissions`: таблица 96 категорий с диапазоном комиссий FBO и FBS (мин–макс), числом предметов и ссылкой на страницу категории; поле поиска по предмету (фильтрация в браузере по всем 7 314 предметам, результат показывает предмет, категорию, ставки и ссылку);
   - страница категории `/reference/wb-commissions/<slug>` (slug через `slugify` из задачи 009): H1 «Комиссия Wildberries в категории „…“», абзац с диапазоном и средней ставкой, таблица предметов (предмет, FBO %, FBS %, разница), сортировка по столбцам, поле фильтра. Внизу ссылка «Рассчитать прибыль для этой категории» на `/calculator`.
   - `title` вида «Комиссия Wildberries в категории „Красота“ в 2026 году: ставки FBO и FBS по предметам», `description` до 160 символов с диапазоном ставок.
2. Большие категории (до 543 предметов) рендерить целиком в HTML, без пагинации: это важно для индексации. Фильтр и сортировка работают поверх уже отрендеренной таблицы.
3. Дата актуальности из `tariffMeta` на каждой странице (компонент `TariffDateNote`).
4. Экономия веса: страницы категорий импортируют только свою часть данных. Сделай скрипт или модуль, который разбивает JSON на файлы по категориям (`src/calculator/data/commissions/<slug>.json`) на этапе `generate:wb-tariffs`, либо используй динамический импорт по категории. Общий 1,6 МБ чанк на страницах справочника грузиться не должен (см. задачу 008).
5. Тесты: число страниц категорий равно числу уникальных категорий; slug уникальны; на странице самой большой категории есть все её предметы; диапазон на хабе совпадает с мин/макс по данным.

## Критерии готовности

- `npm run check` проходит, сборка укладывается в разумное время (до 3 минут на Node 18 в Actions).
- `dist/reference/wb-commissions/index.html` и `dist/reference/wb-commissions/<slug>/index.html` для всех категорий существуют и содержат таблицы в HTML.
- Все адреса в `sitemap.xml`.
- Хаб `/reference` показывает карточку «Комиссии WB».

## Не делать

- Не создавать страницы на каждый предмет (7 314 страниц): это отдельное решение после анализа спроса.
- Не менять значения ставок.
