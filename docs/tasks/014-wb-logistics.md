# 014. Калькулятор логистики и хранения WB /tools/wb-logistics

## Цель

Запросы «калькулятор логистики wildberries», «стоимость хранения вб», «сколько стоит доставка до клиента wb по габаритам». Отдельный быстрый расчёт логистики без всей юнит-экономики.

## Что сделать

1. Чистые функции `src/app/tools/wb-logistics/calc.ts`, переиспользующие `calculateVolumeLiters`, `calculateBaseLogistics`, `detectCargoType`, `calculatePalletCapacity` из `src/app/lib/calculateUnitEconomics.ts` и данные `tariffRegistry.wb.warehouses`, `geoPresets`, `defaults`:
   - `calcLogistics({ lengthCm, widthCm, heightCm, weightKg, warehouse | geoPresetId, localizationIndex, buyoutRatePercent })` → литраж, тип груза (обычный / КГТ), базовая логистика, надбавка коэффициента склада, надбавка локализации, прямая логистика, обратная логистика на единицу с учётом выкупа, итого логистика на проданную единицу;
   - `calcStorage({ volumeLiters, days, warehouse, units })` → стоимость хранения в день и за период на единицу и на партию;
   - `calcPallet(...)` → сколько единиц на монопаллету.
   Формулы и константы брать только из существующей логики калькулятора, чтобы результаты совпадали с `/calculator` при тех же входных данных. Не вводить новые тарифы.
2. Страница через `ToolPage`: габариты и вес, выбор склада (список из `warehouseTariffs` с коэффициентами рядом) или гео-пресета, индекс локализации (слайдер), процент выкупа, дни хранения, единиц в партии. Значения по умолчанию: 30×20×10, 1 кг, Коледино, выкуп 90%, 30 дней, 100 единиц.
3. Результат: таблица статей логистики с пояснением каждой строки, хранение за период, итог на единицу; подсказка «при выкупе 70% логистика на проданную единицу вырастет до …» (пересчёт).
4. «Как считается» с формулой и FAQ 4 вопроса: из чего состоит логистика WB; что такое коэффициент склада и ИЛ; как выкуп влияет на логистику; как снизить логистику (упаковка, литраж, склад).
5. Реестр: `related: ['wb-calculator', 'fbo-vs-fbs', 'break-even']`, ссылки на `/reference/wb-warehouses`.
6. Тесты: для входа по умолчанию результат логистики совпадает с `logisticsBreakdown` из `calculateUnitEconomics` на тех же входных данных с точностью до копейки; при выкупе 100% обратная логистика равна 0; КГТ определяется по порогу из `detectCargoType`.

## Критерии готовности

- `npm run check` проходит; страница отрендерена, в sitemap; 375px без горизонтального скролла; результат виден при открытии.
