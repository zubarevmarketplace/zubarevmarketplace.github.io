# 011. Справочник складов Wildberries

## Цель

Страницы под запросы «склад wildberries коледино коэффициент», «склад казань wb логистика». Данные: `src/calculator/config/warehouseTariffs.ts` (7 складов, коэффициенты логистики, хранения, FBS), `data/raw/warehouse-coefficients.xlsx` как источник. Если в xlsx есть больше складов или поля (адрес, регион), расширь генератор `scripts/generate-wb-tariffs.ts`, чтобы они попали в `warehouseTariffs.ts`; если нет, работай с тем, что есть, и так и напиши в отчёте.

## Что сделать

1. Поставщик `src/app/content/wb-warehouses/pages.ts`:
   - хаб `/reference/wb-warehouses`: таблица складов с коэффициентами логистики, хранения и FBS, пометка «FBS недоступен» для `null`, ссылка на страницу склада и на калькулятор логистики (`/tools/wb-logistics`, появится в задаче 014; до тех пор ссылка скрыта по правилу AGENTS.md);
   - страница склада `/reference/wb-warehouses/<slug>`: H1 «Склад Wildberries …: коэффициенты логистики и хранения», карточка коэффициентов, пример расчёта логистики для товара 30×20×10 см через `calculateBaseLogistics` и коэффициент склада (словами и числом), в каких гео-пресетах склад участвует и с каким весом (из `geoPresets`), ссылки на другие склады.
2. Блок «Как читать коэффициенты»: что такое коэффициент склада, почему он меняется, где смотреть актуальный в кабинете. Без выдуманных адресов и дат: если адреса склада нет в данных, не писать его.
3. Дата актуальности из `tariffMeta`.
4. Тесты: страниц ровно столько, сколько складов в `warehouseTariffs`; slug уникальны; пример расчёта на странице совпадает с `calculateBaseLogistics` × коэффициент.

## Критерии готовности

- `npm run check` проходит.
- `dist/reference/wb-warehouses/index.html` и страницы складов существуют, с H1 и таблицами в HTML, адреса в sitemap.
- Хаб `/reference` показывает карточку «Склады WB».

## Не делать

- Не добавлять склады, которых нет в данных репозитория.
