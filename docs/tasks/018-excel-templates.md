# 018. Шаблоны Excel для селлеров /templates

## Цель

Запросы «таблица юнит-экономики wildberries скачать», «шаблон excel для расчёта прибыли на маркетплейсе», «abc анализ товаров excel шаблон». Скачиваемые файлы без регистрации плюс страницы с описанием.

## Что сделать

1. Скрипт `scripts/generate-templates.ts` на библиотеке `xlsx` (уже в зависимостях) генерирует в `public/templates/` на этапе сборки (добавить в `npm run build` до prerender) три файла с формулами, а не только значениями:
   - `unit-economics-wb.xlsx`: лист «Расчёт» с 10 строками товаров: цена, СПП, себестоимость, комиссия %, логистика, хранение, ДРР %, налог %, прибыль, маржа, ROI (формулы Excel в ячейках), лист «Справка» с описанием столбцов и датой тарифов;
   - `supply-plan.xlsx`: план поставки: продажи в день, дни запаса, остаток, страховой запас, к поставке (формулы), лист с примером;
   - `abc-analysis.xlsx`: столбцы товар, выручка, доля, накопленная доля, группа (формулы с сортировкой инструкцией в «Справке»).
   Формулы на английском (`SUM`, `IF`), тексты на русском. Проверь, что файлы открываются: тест читает файл через `xlsx` и проверяет наличие листов, заголовков и формул в ожидаемых ячейках.
2. Контентные страницы (поставщик `src/app/content/templates/pages.ts`, секция `templates`): хаб `/templates` и по странице на шаблон `/templates/<slug>`: что внутри, скриншот не нужен, таблица столбцов, кнопка «Скачать .xlsx», как заполнять, ссылка на онлайн-инструмент, который считает то же самое.
3. Хаб `/reference` и `/tools` получают ссылку на `/templates`. В `Header` отдельный пункт не нужен.
4. JSON-LD на страницах шаблонов: `DigitalDocument` или `SoftwareSourceCode` не нужны, достаточно `BreadcrumbList`.

## Критерии готовности

- `npm run check` проходит; три файла есть в `dist/templates/`, страницы отрендерены, адреса в sitemap.
- Файлы весят меньше 100 КБ каждый.

## Не делать

- Не вшивать в шаблоны весь справочник комиссий: достаточно ячейки для ручного ввода ставки и ссылки на `/reference/wb-commissions`.
