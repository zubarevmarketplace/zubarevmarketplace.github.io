# 019. Интерактивные чек-листы /reference/checklists

## Цель

Запросы «чек-лист запуска товара на wildberries», «что проверить перед поставкой на вб», «чек-лист карточки товара». Страницы с интерактивными списками, прогресс сохраняется в браузере.

## Что сделать

1. Данные `src/app/content/checklists/items.ts`: четыре чек-листа по 15–30 пунктов, сгруппированных по этапам: «Запуск товара на WB», «Подготовка поставки FBO», «Аудит карточки товара», «Еженедельная проверка магазина». Каждый пункт: `id`, `text`, `hint?` (почему это важно, 1–2 предложения), `tool?` (slug инструмента или путь справочника, где это проверить). Тексты нейтральные, без выдуманных правил площадки и без чисел, которые могут устареть.
2. Поставщик `src/app/content/checklists/pages.ts`: хаб `/reference/checklists` и страницы `/reference/checklists/<slug>`. Компонент чек-листа: чекбоксы, прогресс «12 из 24», кнопка «Сбросить», состояние в `localStorage` по ключу чек-листа, доступ к `localStorage` только в `useEffect`, при SSR все пункты не отмечены. Кнопка «Скопировать как текст» формирует markdown-список в буфер обмена.
3. JSON-LD `HowTo` на страницах чек-листов (шаги из этапов).
4. Хаб `/reference` показывает карточку «Чек-листы».
5. Тесты: id пунктов уникальны внутри чек-листа; все `tool` существуют; тест компонента: клик по пункту увеличивает прогресс, сброс обнуляет.

## Критерии готовности

- `npm run check` проходит; страницы отрендерены, в sitemap; на 375px без горизонтального скролла; прогресс сохраняется после перезагрузки страницы.
