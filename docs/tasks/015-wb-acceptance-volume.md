# 015. Литраж, паллеты и приёмка WB /tools/wb-volume

## Цель

Запросы «калькулятор литража wildberries», «сколько коробов на паллету», «стоимость приёмки вб калькулятор». Небольшой универсальный инструмент для подготовки поставки.

## Что сделать

1. Чистые функции `src/app/tools/wb-volume/calc.ts`:
   - литраж единицы из габаритов (`calculateVolumeLiters`), литраж партии, тип груза;
   - короба: по габаритам короба и единицы считать, сколько единиц входит в короб (простая укладка по трём осям с перебором ориентаций), сколько коробов нужно на партию;
   - паллеты: сколько коробов на паллету 120×80 при максимальной высоте из `palletConfig`, сколько паллет на партию;
   - приёмка: стоимость = литраж партии × коэффициент приёмки за литр, который пользователь вводит вручную (поле с подсказкой «коэффициент на дату поставки смотрите в кабинете WB, он меняется ежедневно»), по умолчанию 0. Базовых ставок приёмки в репозитории нет, не выдумывать.
2. Страница через `ToolPage`: габариты и вес единицы, количество, габариты короба (по умолчанию 60×40×40), коэффициент приёмки. Результат: литраж единицы и партии, тип груза, единиц в коробе, коробов, паллет, стоимость приёмки при введённом коэффициенте, ссылка на `/tools/wb-logistics` для расчёта логистики.
3. FAQ 4 вопроса: как WB считает литраж; что считается крупногабаритом; как уложить товар в короб плотнее; где смотреть коэффициент приёмки.
4. Реестр: `related: ['wb-logistics', 'wb-calculator', 'fbo-vs-fbs']`.
5. Тесты: литраж 30×20×10 равен 6 л; в короб 60×40×40 входит 16 единиц 30×20×10; приёмка при коэффициенте 0 равна 0; количество коробов округляется вверх.

## Критерии готовности

- `npm run check` проходит; страница отрендерена, в sitemap; 375px без горизонтального скролла.
