# 016. Калькулятор СПП и цены для покупателя /tools/spp

## Цель

Запросы «спп вайлдберриз калькулятор», «как посчитать цену до спп», «что получает продавец при скидке wb». Самый простой инструмент волны, но частотный запрос.

## Что сделать

1. Чистые функции `src/app/tools/spp/calc.ts`: прямой расчёт (цена продавца, скидка продавца %, СПП % → цена для покупателя) и обратный (цена для покупателя, СПП % → цена до СПП). Отдельно показать, что СПП не уменьшает выплату продавцу, а комиссия считается от цены до СПП: используй `calculateCommissionAndAcquiring`-логику из существующего калькулятора или импортируй его функции, чтобы цифры совпадали с `/calculator`. При вводе категории показывать комиссию и выплату продавцу после комиссии и эквайринга.
2. Страница через `ToolPage`: два режима (от цены продавца / от цены покупателя), поля: цена, скидка продавца, СПП (по умолчанию из `defaults.simplePlatformDiscountRate`), категория (опционально). Результат: цепочка цен в виде шагов «цена без скидки → цена продавца → цена для покупателя», выплата продавцу при выбранной категории.
3. FAQ 4 вопроса: что такое СПП; кто платит за СПП; почему цена для покупателя меньше, а выплата не меняется; как СПП влияет на комиссию.
4. Реестр: `related: ['wb-calculator', 'price-for-margin', 'break-even']`, ссылка на термин в словаре `/reference/glossary/spp`, если он есть.
5. Тесты: 2 500 ₽ при СПП 30% даёт 1 750 ₽ покупателю; обратный расчёт возвращает 2 500 ₽; комиссия при категории совпадает с `calculateUnitEconomics`.

## Критерии готовности

- `npm run check` проходит; страница отрендерена, в sitemap; 375px без горизонтального скролла.
