Как планировщик использует данные Google Calendar

Оператор приложения — Николай Зубарев. По вопросам обработки данных пишите на zubarev.marketplace@gmail.com. Эта страница описывает приложение «ZubarevLab Планировщик дня». Для посетителей основного сайта действует отдельная политика.

Какие данные получает приложение

После согласия владельца Google предоставляет приложению разрешение calendar.events, которое технически позволяет просматривать и изменять мероприятия во всех календарях аккаунта. Текущая версия читает мероприятия основного календаря: название, время начала и окончания, статус занятости и идентификатор события. Google API также возвращает другие поля мероприятия, но планировщик не передаёт модели его описание, участников и ссылки на видеовстречи.

Для чего используются данные

Время мероприятий помогает найти свободные периоды и не ставить рабочие блоки поверх известных обязательств. Название и время событий могут передаваться поставщику модели OpenAI через локальный OpenClaw Gateway при обработке команды планирования. По запросу владельца планировщик создаёт рабочие блоки в основном календаре и переносит только блоки, которые сам пометил как созданные им. Он не меняет другие события и не отправляет приглашения.

Хранение и передача

Токены Google хранятся в защищённом профиле OpenClaw Gateway на компьютере владельца, отдельно от публичного сайта и исходного кода. Локальное состояние сохраняет идентификатор и время созданных планировщиком блоков. Задачи ведутся в Todoist, сообщения доставляются Telegram; обработка данных этими сервисами и OpenAI регулируется также их собственными условиями и настройками аккаунтов.

Данные Google Calendar используются для функций планирования, не продаются и не используются приложением для рекламы.

Отзыв доступа и удаление

Владелец может отозвать разрешение приложения в настройках своего Google-аккаунта. Чтобы удалить локальные токены и состояние планировщика, он может обратиться по адресу zubarev.marketplace@gmail.com. После отзыва разрешения приложение перестанет получать новые данные календаря. Данные, уже обработанные сторонними сервисами, подчиняются их собственным правилам хранения и удаления.
